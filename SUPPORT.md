# Support

Welcome! This page is the fastest way to get help with `aliasx` with the least back-and-forth.

## Choose the right place

| You want to...                       | Go to...                                                                   |
| ------------------------------------ | -------------------------------------------------------------------------- |
| Ask a question / discuss design      | 💬 [Discussions](https://github.com/comstrx/aliasx/discussions)            |
| Report a reproducible bug            | 🐞 [Issues](https://github.com/comstrx/aliasx/issues)                      |
| Report a security issue (private)    | 🔒 [Security](https://github.com/comstrx/aliasx/security/advisories/new)   |
| Review recent changes                | 🧾 [Commits](https://github.com/comstrx/aliasx/commits/main)               |

---

## Before you post

- Search existing Issues and Discussions first.
- Confirm you are testing against the latest supported aliasx version.
- Reduce the problem to the smallest reproducible input, skill, source, or pipeline step.
- Remove secrets and private project context before sharing examples.

If the problem cannot be reproduced reliably, it is much harder to diagnose reliably.

---

## Bug reports that get solved fast

When opening an Issue, include:

- What happened vs. what you expected
- Minimal reproduction or smallest failing skill/source
- aliasx commit, tag, or release
- Relevant pipeline stage: ingest, clean, normalize, validate, version, score, promote, or consume
- Source type and trust level when relevant
- Environment/runtime details when relevant
- Exact validation errors, logs, or output as text

Helpful links:

- [Issues](https://github.com/comstrx/aliasx/issues)
- [Discussions](https://github.com/comstrx/aliasx/discussions)

---

## Skill quality reports

If a skill produces poor or regressed behavior, include:

- skill identifier and version
- expected behavior
- observed behavior
- minimal evaluation case
- model/agent/runtime context when relevant
- previous known-good version if this is a regression
- source or provenance information when relevant

---

## Scope and expectations

We are happy to help with:

- ✅ Reproducible bugs and regressions
- ✅ Skill ingestion and normalization failures
- ✅ Validation and compatibility issues
- ✅ Skill quality regressions with reproducible evaluations
- ✅ Documentation gaps and examples
- ✅ Clarifying intended aliasx behavior

We usually cannot help with:

- ❌ "It is broken" without a reproducible input or logs
- ❌ Debugging heavily modified forks without an upstream reproduction
- ❌ Evaluating private data that cannot be safely shared
- ❌ Security reports through public Issues

`aliasx` is community-driven. There is no guaranteed SLA, but clear and reproducible reports get the fastest response.

Thanks for helping aliasx get smarter without getting messier. 🧠
